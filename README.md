#  Global Layoffs Data Analysis Using MySQL

A complete data analysis project using **MySQL**, from cleaning raw data to performing in-depth analytical queries that uncover trends, correlations, and insights into global layoffs across industries and years.

---

##  Project Overview

This project explores the **Global Layoffs Dataset** through two main stages:  
**Data Cleaning** and **Data Analysis**, using advanced SQL techniques to ensure high data quality and generate meaningful insights.

---

## 🧹 Data Cleaning Phase

- Created a **staging table** and removed duplicates using **CTEs** and `ROW_NUMBER()`.  
- Standardized inconsistent text data (company names, industries, and countries).  
- Handled **missing values**, replaced empty cells, and corrected data types for accurate computation.  
- Converted text-based numbers and dates to numeric and date formats.  
- Removed irrelevant columns and rows with no measurable information.  
- Ensured **clean, reliable, and structured data** ready for analysis.

---

## 📊 Data Analysis Phase

- Identified companies with **100% layoffs** and ranked top impacted firms per year.  
- Performed **industry-level analysis** to compare total layoffs, funds raised, and company stages.  
- Conducted **country and location analysis** to reveal the most affected regions.  
- Used **stored procedures** to dynamically return top industries by city.  
- Examined the correlation between **layoffs and funds raised**, detecting statistical outliers.  
- Analyzed **yearly and quarterly trends** with rolling sums to show global workforce patterns over time.

---
